Questions

Is Money Tycoon 3D really free?

Yes. It is free to download and play, with no ads or purchases. The source code is open under the MIT license.

Does it need to be installed?

No. Download MoneyTycoon3D.exe and double-click it. It runs on Windows 10 and 11 and does not need Python or anything else.

Why does Windows say "Windows protected your PC"?

The game is a small independent project and the exe is not signed with a paid publisher certificate, so Windows SmartScreen shows a warning for new downloads. Click More info, then Run anyway. You can read the full source code on GitHub or build the exe yourself.

Can I play with a controller?

Yes. Everything works with a gamepad, including menus, every mini-game (with an on-screen keypad for typing and maths) and driving with triggers and stick. Xbox-style controllers and most others Windows recognises work, even if you plug them in while the game is running.

Does the game update itself?

Yes. When you start the game it checks for a newer version and offers to update. The download is verified against GitHub's published checksum before it replaces the old one, and your save is kept. You can turn the automatic check off in the pause menu.

Where is my save file?

The game saves automatically to save.json in the same folder as the exe. Keep the exe in its own folder so your progress stays with it.

How does food delivery work?

Start a shift at the Food Delivery kiosk in the Gig Plaza. Accept an order, drive to the restaurant, then to the customer using the GPS. You earn a fare, a speed bonus and tips, reduced if the food gets cold or shaken up in crashes. Better ratings pay more. The map has a river you can only cross on bridges, freeways you enter by ramp, highways and underpasses, so choosing the right route matters.

Can I change the jobs or pay?

Yes. Put a data/jobs.json file next to the exe to override the built-in jobs. The format is in the source code on GitHub.

What about Mac or Linux?

The download is for Windows. The game is written in Python with the Ursina engine, so you can run it from source on other systems by following the steps in the README.
